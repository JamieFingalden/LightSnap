轻截 LightSnap 0.1.4 预览版

运行要求：Apple Silicon Mac，macOS 14 或更新版本。

安装：将 LightSnap.app 拖入 Applications 文件夹，再从“应用程序”打开轻截。
本版本使用本地临时签名，未经过 Apple 公证；首次打开可能需要通过 macOS 的“隐私与安全性”设置确认。

快捷键：Control + 1 截图，Control + 2 长截图，Control + 3 打开／结束录屏，Control + 4 暂停／继续录屏；截图标注时 Command + T 贴图。
贴图支持拖动、缩放；双击或右键选择“关闭该贴图”关闭。

智能选区：截图时悬停自动描边，单击选中，拖动手动框选；普通截图按空格选择当前屏幕。
选区和标注界面支持 Esc、右键或触摸板双指辅助点按取消。触摸板需开启 macOS 的对应辅助点按手势。
识别窗口内控件需在轻截“设置 → 设置元素定位权限”中开启辅助功能权限；未开启时仍可定位窗口。
选好区域后默认使用移动工具：拖动选区内空白处调整位置，拖动四边或四角调整大小；调整时保留已有标注与撤销记录。点击矩形、箭头等工具后才开始绘制。

录屏：支持屏幕、窗口和区域，可选系统声音、麦克风与摄像头。结束后调整自动缩放、鼠标效果、背景、画布比例与音量，导出 MP4 或 GIF；不提供字幕和时间轴编辑器。
录屏原片与样式自动保存在“桌面 / LightSnap”，MP4 和 GIF 默认导出到桌面，也可另选保存位置。

首次截图或录屏需要在“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”中允许轻截，然后按系统提示退出并重新打开。
更新后若旧授权失效，可删除旧的轻截授权条目，重新添加“应用程序”里的轻截并开启权限，再退出并重新打开。麦克风和摄像头仅在选用时请求对应权限。
