轻截 LightSnap 0.1.0 预览版

运行要求：Apple Silicon Mac，macOS 14 或更新版本。

安装：将 LightSnap.app 拖入 Applications 文件夹，再从“应用程序”打开轻截。
本版本使用本地临时签名，未经过 Apple 公证；首次打开可能需要通过 macOS 的“隐私与安全性”设置确认。

快捷键：Control + 1 截图，Control + 2 长截图；截图标注时 Command + T 贴图。
贴图支持拖动、缩放；双击或右键选择“关闭该贴图”关闭。

首次截图需要在“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”中允许轻截，然后按系统提示退出并重新打开。
已授权后仍提示拒绝的问题尚待实机验证。更新后若旧授权失效，可删除旧的轻截授权条目，重新添加“应用程序”里的轻截并开启权限，再退出并重新打开。
