# 录屏

轻截的录屏流程参考 [Screen Studio](https://screen.studio/)：选择来源，录制操作，调整整体样式，导出成片。实现使用 ScreenCaptureKit、AVFoundation、Core Image 和 AppKit／SwiftUI，不引入第三方依赖。

## 使用

1. 从菜单栏「录屏…」或欢迎窗口「开始录屏」进入，选择屏幕、窗口或区域。
2. 按需启用系统声音、麦克风、摄像头和快捷键记录，选择 30 / 60 fps 及倒计时。区域录制会复用截图选区，区域至少为 32 × 32 点。
3. 点击开始。浮动控制条显示时长，提供暂停、继续和结束；控制条和区域边框不进入屏幕录屏。
4. 结束后直接预览，调整整体效果，点击「导出 MP4」。更多菜单提供 GIF、原片文件夹与导出文件复制。

默认快捷键为 Control + 3 打开／结束录屏、Control + 4 暂停／继续。两者与截图快捷键一起在轻截设置中修改，四个快捷键不能重复。应用「录屏」菜单的 Command + O 可以打开已有录屏。

## 画面与声音

- 自动镜头：根据点击生成缩放，平滑跟随操作，在结束前恢复全景。竖屏和方形输出会裁切画面并跟随鼠标，避免超出源画面边界。
- 鼠标：保留系统光标图像与位置，可调整大小、平滑移动、闲置隐藏和点击圆环。
- 背景：六组内置背景或自选图片，可调整留白、圆角与阴影。屏幕和区域录制可过滤桌面图标，不修改桌面系统设置。
- 摄像头：作为单独原片保存，预览时可开关、镜像、切换形状、位置和大小；鼠标靠近时会缩小，减少遮挡。
- 声音：系统声音与麦克风保存在独立音轨，预览可分别调节音量。MP4 导出时混合为一个音轨，兼容常见播放器。两路声音与视频共用时钟，暂停期间不进入成片。
- 快捷键：可选记录 Command 或 Control 组合，预览中显示短提示。不记录普通正文输入。

预览只有播放、定位和整体样式设置，不提供字幕、剪切、变速或时间轴编辑。默认样式可保存供以后录制使用；自选背景图片保留在当前录屏中，默认样式使用内置背景。

MP4 输出提供 720p、1080p、1440p、4K 及 30 / 60 fps。4K 的画布长边为 3840 像素，竖屏对应 2160 × 3840；放大低分辨率原片不会增加真实细节。GIF 最长 30 秒，固定为长边 960 像素、15 fps、循环播放，不带声音。

## 权限与文件

屏幕、窗口和区域需要 macOS「屏幕与系统音频录制」权限；只有启用麦克风或摄像头时才请求对应权限。快捷键记录需要辅助功能权限，录屏与鼠标效果本身不依赖它。

本地构建采用临时签名，系统可能拒绝沿用旧授权。在系统设置中移除旧的轻截条目，添加当前构建的 `dist/LightSnap.app`，开启屏幕录制授权后重新启动。设置窗口显示权限错误时，仍可打开已有录屏进行预览和导出。

每次录屏在「桌面 / LightSnap」中建立独立文件夹，保存 `screen.mov`、可选的 `camera.mov`、光标图像和 `recording.json`。MP4 与 GIF 导出默认打开桌面，也可在保存窗口选择其他位置。关闭预览与取消导出不删除原片；导出成功后才替换目标文件。通过原片文件夹或其中的 `recording.json` 重新打开。文件保存在本机，不自动上传。

采集出错时尝试保留已写入部分。原片采用分段写入以提高异常退出时的可恢复性；进程崩溃或磁盘写入失败时不能保证整段录屏完整，尚未结束的记录可在文件夹中检查原始 MOV。

## 验证

```sh
zsh scripts/build.sh
zsh scripts/check-recording.sh
```

录屏检查在 macOS 桌面环境运行，不访问真实屏幕、麦克风或摄像头。它向实际录制写入器输入合成视频、摄像头和两路音频，验证暂停时钟、副屏负坐标、缩放边界、末帧补齐、音轨同步、预览与 MP4／GIF 导出。演示文件输出到 `.build/recording-check/`。

实际屏幕权限、系统声音和不同显示器的采集表现仍需在授权后的桌面环境验证。真实麦克风和摄像头需连接对应硬件验证。
