# 轻截 LightSnap v0.1.5

贴图缩放改为符合实际使用习惯：鼠标滚轮和触控板捏合都可以缩放，缩放以光标位置为中心。

## 更新内容

- 鼠标滚轮向前推放大、向后拉缩小，不受「自然滚动」设置影响；缩放范围 10% 到 500%。
- 触控板和 Magic Mouse 的双指滚动仍用于查看超出屏幕的长图，按住 Command 滚动则缩放；鼠标按住 Option 滚动可滚动长图。
- 修正触控板捏合无效的问题。macOS 只把捏合手势发给前台应用，而轻截是不激活的菜单栏应用；现在在已开启辅助功能权限时，轻截会把落在贴图上的捏合转发给贴图。轻截不会为此主动弹出授权请求，没有权限时滚轮、Command + 滚动和快捷键照常可用。
- 缩放以光标位置为中心，长图超出屏幕时同步调整滚动位置，边框继续贴合图片。
- 设置窗口的权限说明补充了贴图捏合；在系统设置中开启权限后回到设置窗口即可生效，不必重新贴图。

## 安装

下载 `LightSnap-0.1.5-arm64.dmg`，将 LightSnap 拖入 Applications。仅支持 Apple Silicon，需 macOS 14 或更新版本。随附的 `.sha256` 文件可用于校验安装包。

应用采用临时签名，未经过 Apple 公证。首次打开可能需要在 macOS「隐私与安全性」中确认；更新后若屏幕录制或辅助功能授权失效，请移除旧条目并重新添加已安装的轻截。

## 验证

通过 Apple Silicon Release 构建、代码签名完整性与 DMG 校验。贴图检查覆盖快捷键、滚轮与捏合缩放贴合、同一手势不重复应用、屏幕边界、双击与菜单关闭，以及检查进程不在前台时的捏合转发；选区与录屏检查通过。
