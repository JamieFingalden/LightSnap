# 轻截 LightSnap v0.1.8

长截图的帧间重叠识别改为两级匹配：快速像素比对拿不准时，自动调用系统 Vision 图像配准复核，仍无法唯一确定重叠时才提示回滚。此前频繁出现"重叠不明确"的低对比、细密纹理等场景，现在多数可以自动对齐。

## 更新内容

- 两级重叠匹配：保留原有快速像素比对作为初筛（无滚动、可确定拼接时行为与耗时不变）；初筛不确定时改用 Vision 的平移图像配准（`VNTranslationalImageRegistrationRequest`）计算帧间精确平移，再交回像素校验裁决。配准只在不确定帧上触发，不增加常规帧的处理开销。
- 拼接安全不变：配准给出的平移必须通过像素误差与对比度阈值、且全范围不存在等价平移对手时才拼接；周期性重复列表等内容依旧拒绝静默拼接，无重叠的两帧即使经过配准也不会误拼。
- 滚动速度提示：单帧滚动超过半屏时提示放慢速度；连续重叠不明确时给出针对滚动速度的具体建议，代替单一的回滚提示。
- 包含 v0.1.7 的贴图缩放漂移修正。v0.1.7 未单独发布，从 v0.1.6 及更早版本升级后同时生效。

## 安装

下载 `LightSnap-0.1.8-arm64.dmg`，将 LightSnap 拖入 Applications。仅支持 Apple Silicon，需 macOS 14 或更新版本。随附的 `.sha256` 文件可用于校验安装包。

应用采用临时签名，未经过 Apple 公证。首次打开可能需要在 macOS「隐私与安全性」中确认；更新后若屏幕录制或辅助功能授权失效，请移除旧条目并重新添加已安装的轻截。macOS 27 中辅助功能权限位于 系统设置 → 隐私与安全性 → 「允许辅助应用程序控制电脑」。

## 验证

通过 Apple Silicon Release 构建、代码签名完整性与 DMG 校验。九项单元测试覆盖滚动偏移、无重叠与重复内容拒绝、Vision 配准还原已知偏移与歧义拒绝、分块合成方向、标注位置、PNG 复制像素一致性、像素上限和临时文件释放，Debug 与 Release 模式全部通过。
