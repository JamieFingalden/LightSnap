# 轻截 LightSnap v0.1.7

修正贴图缩放时窗口向左下角漂移的问题：连续捏合、滚轮或快捷键缩放时，贴图不再逐步偏移，光标下的图片点始终保持在光标下。

## 更新内容

- 修正缩放漂移：系统会把窗口位置对齐到整点，此前缩放按分数尺寸请求窗口、再从对齐后的窗口反推缩放锚点，舍入误差在连续缩放事件中累积，贴图以每秒数十点的速度向左下角漂移。现在锚点、图片与窗口尺寸全部取整，请求与实际窗口一致，并把图片尺寸量化到偶数消除取整偏向；放大再缩小回原倍率后，贴图位置精确复原。
- 缩放中心行为不变：光标在贴图上时以光标为中心，不在贴图上时以贴图中心为中心，范围仍为 10% 到 500%。

## 安装

下载 `LightSnap-0.1.7-arm64.dmg`，将 LightSnap 拖入 Applications。仅支持 Apple Silicon，需 macOS 14 或更新版本。随附的 `.sha256` 文件可用于校验安装包。

应用采用临时签名，未经过 Apple 公证。首次打开可能需要在 macOS「隐私与安全性」中确认；更新后若屏幕录制或辅助功能授权失效，请移除旧条目并重新添加已安装的轻截。macOS 27 中辅助功能权限位于 系统设置 → 隐私与安全性 → 「允许辅助应用程序控制电脑」。

## 验证

通过 Apple Silicon Release 构建、代码签名完整性与 DMG 校验。缩放锚点经探针验证：中心锚点与光标锚点两种模式各三轮「放大-回落」循环，窗口残余位移均为 0；贴图、选区与录屏检查脚本通过。
