# 轻截 LightSnap v0.1.0 预览版

面向 Apple Silicon 的 macOS 原生截图工具，要求 macOS 14 或更新版本。

## 安装

下载 `LightSnap-0.1.0-arm64.dmg`，将 `LightSnap.app` 拖入 `Applications` 后打开。随附的 `.sha256` 文件可用于校验下载文件。

## 功能

- Control + 1 区域截图，Control + 2 手动纵向长截图。
- 浮动工具栏提供矩形、椭圆、箭头、直线标注、颜色与线宽、撤销重做、复制和 PNG／JPEG 保存。
- 截图标注时 Command + T 贴图；窗口随图片缩放，支持拖动移动、双击关闭和右键菜单关闭。
- 原生 Swift、AppKit 和 ScreenCaptureKit 实现，无第三方运行依赖，源码采用 MIT 许可证。

## 当前限制

- 已授权后仍弹出权限提示的问题尚未完成实机验证。已修正把其他截图错误误报为权限问题的判断，但不代表系统授权问题已解决。
- 此安装包使用临时签名，未经过 Apple 公证。更新后旧的屏幕录制授权可能失效，需要删除旧条目，重新添加当前安装的应用并授权。
- 长截图仅支持手动向下滚动；固定栏、动画、重复内容和快速滚动可能影响拼接。单图最多六千万像素，完整导出时会出现内存峰值。

已通过 ARM64 构建、代码签名完整性校验、七项核心测试及贴图窗口专项检查；演示图上的标注、保存、复制、贴图缩放和关闭已验证。
