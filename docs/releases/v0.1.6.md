# 轻截 LightSnap v0.1.6

录屏背景升级为致敬 macOS 历代系统壁纸的渐变配色，并支持一键把当前桌面壁纸设为录屏背景；设置窗口显示版本号，预览不再出现误导性的黑边。

## 更新内容

- 录屏背景预设改为七款致敬 macOS 系统壁纸的配色：金门海峡、太浩湖、红杉、大瑟尔、卡特琳娜岛、索诺马、蒙特雷，默认背景为金门海峡。背景由底色渐变叠加多层柔和光斑程序化绘制，有系统壁纸般的层次质感；预览与导出共用同一渲染，纯白与纯黑背景保持纯净。
- 背景图片菜单新增「使用当前桌面壁纸」，直接读取系统当前设定的桌面壁纸作为录屏背景，换壁纸后一键同步；动态航拍壁纸无法作为静态背景时会给出提示。
- 旧录屏记录与已保存样式中的「极光、海蓝、日落、石墨」背景自动映射到最接近的新样式，已有文件不受影响。
- 修正录屏预览上下出现黑边的问题。黑边来自播放器 letterbox，导出文件本身没有黑边；现在预览播放器严格按照输出视频的比例显示，预览所见即导出所得，切换原始、横屏、竖屏和方形画布时同步生效。
- 设置窗口底部显示当前版本号与构建号；未打包直接运行时提示开发版，便于区分源码运行与安装版。

## 安装

下载 `LightSnap-0.1.6-arm64.dmg`，将 LightSnap 拖入 Applications。仅支持 Apple Silicon，需 macOS 14 或更新版本。随附的 `.sha256` 文件可用于校验安装包。

应用采用临时签名，未经过 Apple 公证。首次打开可能需要在 macOS「隐私与安全性」中确认；更新后若屏幕录制或辅助功能授权失效，请移除旧条目并重新添加已安装的轻截。

## 验证

通过 Apple Silicon Release 构建、代码签名完整性与 DMG 校验。七款背景以与渲染器相同的参数做过预览渲染检查；录屏预览比例与输出比例联动，预览与导出画面一致。核心测试、贴图、选区与录屏检查脚本通过。
