# 轻截 LightSnap v0.1.9

修正 v0.1.8 引入的配准复核漏洞：重复纹理的等价平移若不落在对手扫描的采样格点上，长截图可能在错误平移上拼接，造成丢行或重复行。

## 更新内容

- 对手复核改为逐行全范围扫描：v0.1.8 的配准复核按固定步长抽样检查等价平移，当重复内容的周期使等价平移全部落在采样格点之外（例如等价平移均为 7、27、47… 而采样点为 1、5、9…）时，对手永远不被发现，配准结果会在错误位置拼接。现在对全部候选平移逐行比对，任何等价对手都会维持"重叠不明确"提示。
- 行为与性能影响：本应拒绝的重复内容场景恢复拒绝；常规拼接路径不变，逐行扫描仅在不确认帧上执行，为纯灰度行比对，耗时毫秒级。
- 新增两项回归测试：等价平移在采样格点之外时逐行扫描必须发现对手（含非周期内容不误报的负例），以及带横向纹理的周期内容经配准复核后仍被拒绝。

## 安装

下载 `LightSnap-0.1.9-arm64.dmg`，将 LightSnap 拖入 Applications。仅支持 Apple Silicon，需 macOS 14 或更新版本。随附的 `.sha256` 文件可用于校验安装包。

应用采用临时签名，未经过 Apple 公证。首次打开可能需要在 macOS「隐私与安全性」中确认；更新后若屏幕录制或辅助功能授权失效，请移除旧条目并重新添加已安装的轻截。macOS 27 中辅助功能权限位于 系统设置 → 隐私与安全性 → 「允许辅助应用程序控制电脑」。

## 验证

通过 Apple Silicon Release 构建、代码签名完整性与 DMG 校验。十一项单元测试 Debug 与 Release 模式全部通过。
