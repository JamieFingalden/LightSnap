# 轻截 LightSnap v0.1.4

新增屏幕、窗口和区域录制，录完即可预览、调整整体样式并导出成片。

## 更新内容

- 支持系统声音、麦克风、摄像头画中画、倒计时，以及录制中的暂停、继续和结束。
- 新增自动缩放、平滑与放大鼠标、闲置隐藏、点击动效和可选的快捷键提示。
- 可调整背景、留白、圆角、阴影、摄像头布局和独立音量，支持原始比例、横屏、竖屏和方形画布。
- 支持最高 4K / 60 fps 的 MP4，以及 30 秒以内、960 px / 15 fps 的 GIF。
- 原片与样式自动保存在「桌面 / LightSnap」，MP4 和 GIF 默认导出到桌面；已保存的录屏可重新打开。
- 默认使用 Control + 3 打开／结束录屏，Control + 4 暂停／继续录屏，可在设置中修改。

本版本不提供 iPhone／iPad 屏幕录制、字幕和时间轴编辑器。

## 安装

下载 `LightSnap-0.1.4-arm64.dmg`，将 LightSnap 拖入 Applications。仅支持 Apple Silicon，需 macOS 14 或更新版本。随附的 `.sha256` 文件可用于校验安装包。

应用采用临时签名，未经过 Apple 公证。首次打开可能需要在 macOS「隐私与安全性」中确认；更新后若屏幕录制授权失效，请移除旧条目并重新添加已安装的轻截。麦克风和摄像头只在选用时请求权限。

## 验证

通过 Apple Silicon Release 构建、代码签名完整性与 DMG 校验。录屏专项检查覆盖暂停时钟、副屏坐标、自动缩放、静止末帧、独立音轨同步、摄像头合成、预览和 MP4／GIF 导出。
